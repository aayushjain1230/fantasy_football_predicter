# Screenshot Guide

Use demo mode for all public screenshots.

Recommended screenshots:

- Home weekly brief
- My Team lineup recommendation
- My Team waiver recommendation
- My Team trade evaluation
- League playoff outlook
- Players detail

Rules:

- Do not include ESPN cookies, API keys, private league IDs, or personal information.
- Keep the `Demo league` label visible.
- Do not crop out limitation or provider-status context when it materially affects the result.
- Do not use mockups as evidence of deployed functionality.

Manual capture steps:

1. Run `streamlit run streamlit_app.py`.
2. Use demo mode.
3. Set browser width around 1440px for desktop captures and around 390px for mobile captures.
4. Navigate through Home, My Team, Players, League, and Settings.
5. Save screenshots under a local ignored folder such as `screenshots/`.
